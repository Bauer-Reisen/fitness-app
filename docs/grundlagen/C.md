# Agent C – Gerätekatalog (Planung)

Hinweis vorab: Die Liste beruht auf allgemeinem Wissen über übliche Studioausstattung, ohne Webrecherche.
Gesamtvermerk: Vermutung, nicht geprüft: Welche Geräte ein bestimmtes Studio hat, wie sie heißen und wie ihre
Anzeigen aussehen, ist je nach Hersteller (z. B. gym80, Technogym, Life Fitness, Matrix) verschieden. Deshalb sind alle
Einträge Vorlagen, die der Nutzer im Studio abhakt und anpasst.

Legende Belastung: KG = Steckgewicht/Gewichtsstapel (kg oder Stufen-Nr.), KÖ = Körpergewicht (Wdh.),
ZEIT = Haltezeit in Sekunden, AUS = Ausdauer (Dauer + Stufe/Geschwindigkeit/Watt), BALL = Ballgewicht in kg.

## 2. Übungen als eigene Einheit + Datenstruktur

Grund: Eine Übung (z. B. „Rudern") geht an der Rudermaschine und am Kabelzug; „Trizepsdrücken" an Maschine und Seilzug.
Fortschritt wird aber **pro Kombination Übung+Gerät** gezählt, denn 40 kg am Seilzug sind nicht 40 kg an der Maschine.

```
Geraet      { id, name, aliase[], muster, belastungsart: 'kg'|'koerper'|'zeit'|'ausdauer'|'ball',
              skala (siehe 4), einstellungen: [{schluessel:'Sitzhöhe', wert:'4'}], vorhanden: true/false,
              eigen: true/false, vorlageVon: geraetId|null, notiz, fotoId|null }
Uebung      { id, name, aliase[], muster, muskeln[], belastungsart, hinweis (1–2 Sätze Ausführung),
              einseitig: bool }
GeraetUebung{ id, geraetId, uebungId, einstellungenExtra: [{schluessel:'Rollenhöhe', wert:'Loch 12'}],
              griff, letzterStand }   // hierauf bezieht sich Fortschritt/Steigerung
```
- Einstellungen am Gerät = gelten für alle Übungen (Sitzhöhe). Einstellungen an GeraetUebung = nur für diese Übung
  (Seilzug-Rollenhöhe, Griff). Beides beim Training direkt anzeigen und mit einem Tipp änderbar.
- Katalog-Vorlage (fest im Code, versioniert) getrennt von Nutzerdaten (IndexedDB). Nutzergerät verweist per
  `vorlageVon` auf Vorlage; Updates der Vorlage überschreiben nie Nutzerwerte.
- Pläne referenzieren nur GeraetUebung-Einträge mit `vorhanden: true`.

## 3. Eigenes Gerät schnell anlegen

Mindestfelder (Version 1): **Name**, **Muster** (5 Knöpfe), **Belastungsart** (5 Knöpfe). Rest optional.
- Weg A „Wie Gerät X": Vorlage wählen → alles kopieren → nur Name/Skala anpassen (z. B. „Brustpresse 2 (blau)").
- Weg B leer: Name + Muster + Belastungsart, dann Skala (siehe 4), dann mind. 1 Übung zuordnen
  (aus Liste wählen, passend zum Muster vorgefiltert, oder neue Übung mit nur Name).
- Gewichtsschritt: Standardvorschlag 5 kg (Vermutung, nicht geprüft: bei vielen Maschinen üblich 5 kg oder 2,5 kg;
  Seilzüge teils 2,5–5 kg); Nutzer kann ändern.
- Einstellungen: Freie Felder „Name: Wert", Vorschläge per Tipp (Sitzhöhe, Rückenlehne, Polster, Griff, Startwinkel).
- Foto: **später** (optional). Grund: Fotos blähen IndexedDB und Backup auf; in Version 1 reicht Freitext-Notiz
  („rechte Reihe, 3. Gerät, grau"). Falls Foto später: verkleinert speichern (z. B. ~800 px), im Backup optional.

## 4. Gewichtsstufen abbilden

Problem: Steckgewicht-Stapel zeigen mal kg, mal nur Platten-Nr.; Stufen sind teils ungleich (erste Platte schwerer,
Zusatz-Halbgewicht oben auf dem Stapel). Lösung: **intern immer eine Stufenliste**, angezeigt wie am Gerät.

```
skala { anzeige: 'kg'|'stufe',
        stufen: [5,10,15,...,100]    // erzeugt aus start/schritt/max, oder frei eingegeben
        zusatz: [0, 1.25, 2.5]       // optionales Kleingewicht/Aufsteckgewicht, sonst [0]
        einheitText: 'kg'|'Platte'|'Stufe' }
Satz  { geraetUebungId, stufenIndex, zusatz, wdh, dauerSek, gefuehl }
```
- Anzeige „Platte 7" oder „35 kg" – genau das, was der Nutzer am Gerät sieht (weniger Fehler beim Ablesen).
- Steigerung rechnet in **Stufen** (nächste Stufe bzw. nächstes Zusatzgewicht), nicht in kg. So funktioniert sie
  auch, wenn kg unbekannt sind.
- Kg-Werte nur zum Vergleich/Diagramm innerhalb desselben Geräts; kein Vergleich zwischen Geräten
  (Vermutung, nicht geprüft: Hebel und Seilumlenkungen, z. B. 1:2 am Seilzug, machen die Anzeige-kg nicht vergleichbar).
- Sonderfall Gegengewicht (Gravitron): Feld `umgekehrt: true` → Steigerung = weniger Unterstützung.
- Körpergewicht: Steigerung über Wdh. → schwerere Variante (Knie-Liegestütz → Liegestütz → Füße erhöht).
- Zeit: Steigerung in Sekunden-Schritten (z. B. +10 s). Ball: Liste vorhandener Ballgewichte wie Stufenliste.
- Ausdauer (Aufwärmen): kein Fortschrittszwang; erfassen Dauer + 1 Wert (Stufe/Watt/km/h). Air Bike/Rudergerät:
  Widerstand kommt von eigener Kraft, deshalb Watt oder Kalorien statt Stufe.
- Wenn Stapel zu Ende (oberste Stufe erreicht): Hinweis „mehr Wdh. oder einbeinig/einarmig".

## Version 1 vs. später

Version 1:
- Feste Vorlagenliste (30 Geräte, ~60 Übungen) mit Abhaken „im Studio vorhanden".
- Gerät–Übung als eigene Verknüpfung; Fortschritt pro Verknüpfung.
- Eigenes Gerät: 3 Pflichtfelder + „wie Gerät X"; Stufenliste mit Start/Schritt/Max oder frei.
- Gemerkte Einstellungen (Sitzhöhe usw.) sichtbar beim Training.
- Kurze Ausführungshinweise als Text (1–2 Sätze), keine Bilder.

Später:
- Fotos vom Gerät, Skizzen/Animationen zur Ausführung.
- Mehrere Studios (Gerätesatz je Studio), Teilen eines Katalogs mit anderen Nutzern (Export/Import-Datei).
- Austauschvorschlag „Gerät besetzt → gleichwertige Übung an anderem Gerät" (über gleiches Muster + Muskeln).
- Herstellerspezifische Vorlagen (Stufenlisten), QR-Code am Gerät scannen.
